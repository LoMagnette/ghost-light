One browser game client (devoxx-game-index) and eight Node command-line checks, all sharing the same src/core physics engine and the same surveyed src/venue building data so that what the checks measure is exactly what a player experiences. The game is deployed to GitHub Pages as an installable, offline-capable PWA.
